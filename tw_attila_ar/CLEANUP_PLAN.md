## 1. Executive Summary & Intent

Over successive iterations of reverse-engineering Attila's font format, wrap mechanics, and UI layouts, the workspace accumulated over **3.2 GB** of generated binaries, unpack caches, PDB debug symbols, duplicate archives, and transient solver scripts.

This cleanup plan isolates all non-essential and redundant files without permanently deleting anything:
- **Zero hard deletes:** Any file removed will be moved into `<WORKDIR>/quarantine/<original_path>` with an exact `MANIFEST.tsv`.
- **Preserved history:** A snapshot commit (`pre-cleanup-snapshot`) and tag (`pre-cleanup-20261010_143319`) have been created. Removals will be committed to a dedicated `cleanup` branch.
- **Safety guarantee:** Active tools, codecs, tests, fonts, and current translations are strictly preserved or held until subsequent phases.

---

## 2. Classification Breakdown

### Category Definitions
- **KEEP:** Actively required for building, running tests, or reference in the localization pipeline.
- **JUNK:** Generated build outputs, test pack binaries, redundant archives, PDB debug symbols, and temporary caches that are 100% regenerable.
- **DEAD:** Historical experimental scripts calling obsolete parameters, superseded solvers, or tools with missing runtimes.
- **BROKEN:** Files failing to execute or parse due to unresolvable errors.
- **LEGACY-LOCALIZATION:** Existing translation catalogs and legacy shaping scripts. **HELD until Phase 3 completes.**
- **UNSURE:** Files requiring user clarification before movement.
